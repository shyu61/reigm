# 東京23区賃貸マンション名に使われるカタカナ語ランキング

街を歩いていると、「○○ヒルズ」「○○ハイツ」「○○タワー」みたいなカタカナのマンション名がやたら目に入ってきませんか？特に賃貸物件を探していると、似たような名前がたくさんあり、それぞれの言葉が何を意味しているのか気になることがあります。

東京23区内には**数万~数十万件規模**で賃貸マンションが存在します。今回はSUUMOから物件名を取得し、**マンション名に使われるカタカナ語**を調査してみました。

調べてみると、これがなかなか面白いことが分かりました。**1位はハイツで僅差で次点がメゾン**、地形系のワードは言葉通りの場所に分布する一方、**「スカイ」は意外にも墨田区に集中していて、どうやら東京スカイツリーを参照しているらしい**…といった具合に、カタカナ語1つから街の文化や歴史が見えてきます。普段なんとなく目にしている物件名も、こうして横断的に集めてみるとそれぞれちゃんと"意味"を持っているのが見えてきて、いつもの街の景色がちょっと違って見えてきます。

## TL;DR

1. **[使用頻度]** メゾンを僅差で抑えて**「ハイツ」が1位**。馴染み深いワードが並ぶが、その裏には地理・ブランド・建物特徴など複数の意味軸が絡んでいた
2. **[標高との関係性]**「ヒルズ」は高台、「ベイ」「リバー」は低地と概ね言葉通りに分布。ただし高さを連想させる**「スカイ」だけが低地に多い**という例外が浮上
3. **[23区エリア別の分布①]**「タワー」は港区など湾岸に集中、「リバー」は隅田川・荒川沿いに広がるなど、**ワードごとに異なる都市文化**が見えてくる
4. **[23区エリア別の分布②]**　最大集中エリアは墨田区で、湾岸タワマンの「空」ではなく、**東京スカイツリーを参照している可能性**が高い → 地理ワードがランドマークのラベルとして機能していた

## 1. 賃貸マンション名で最も使われているカタカナ語は？

今回はマンション名から**形態素ごとにカタカナ語を抽出**してランキング化しました。形態素で分割するとブランド名をバラバラにしちゃったりするので正確ではないと言えばそうなんですが、その点は後で補足するとして、純粋に**「ワードとして何が使われているか？」**を調査しています。

> そもそも「形態素（けいたいそ）」とは、**意味を持つ言語の最小単位**のこと。日本語は英語と違って単語の間にスペースがないため、文章を意味のまとまりごとに区切るには「形態素解析」と呼ばれる処理が必要になります。

具体的には、「グランドメゾン」は「グランド + メゾン」、「シャーメゾン」は「シャー + メゾン」と分解されて、「グランド」「シャー」「メゾン」それぞれが1票としてカウントされます。ブランド単位で見たほうが本当は文化的な分析としては正確ですが、まずは「**個々のワードがどれだけ普及しているか**」というレイヤーで切り出してみよう、というのが今回の方針です。

### ハイツ・メゾンはなぜここまで多いのか？

メゾン（1459件）をわずか**15件差で抑えて、ハイツ（1474件）が堂々の1位**という結果になりました。上位10位までは800件以上が並ぶ激戦区で、皆さんにも馴染み深いワードが揃っています。純粋にいろんな業者がハイツやメゾンを名前に使っているというのもありますし、**積水ハウスの「シャーメゾン」のようなブランド名**として多くのマンションが存在しているというのも一因かもしれません。

そもそも「ハイツ」（英: heights = 高台/高地）も「メゾン」（仏: maison = 家）も外来語ですが、日本の集合住宅命名としてはかなりの古株です。1970年代以降の集合住宅ブームの中で、カジュアルで耳馴染みのいい外国語として広く採用されてきました。今ではほとんど日本語化していると言ってもいいくらいで、新しさやおしゃれさを売りにしたというより、むしろ「**無難で安心できる響き**」として定着しているのが面白いところです。

top10にはほかにも**コート・レジデンス・ハウス・コーポ・パレス**といった定番が並んでいます。どれも言われてみれば確かによく見るワードばかりではないでしょうか。命名の世界でも、流行り廃りの早いものと長く生き残るものがはっきり分かれているようです。

**ハイツとヒルズは、実は全然違う分類**

とはいえ、top10のワードを並べて見比べると、同じカテゴリに入れていいのか怪しい違いも見えてきます。「ハイツ」と「ヒルズ」は見た目も語源も近いのに、実はその"性格"がかなり違う。ここでカタカナ語の分類軸に少し踏み込んでみます。

カタカナ語を扱う上で難しいのは、**背景にある意味がいくつかの軸で構成され、一概に分類できない**点です。ディベブランドとして商標登録されているものもあれば、商標登録はされてないが半固有化されているものもあります。また地理的な意味を持つものもあれば、建物自体に意味を付加するようなものもあります。試しに**私なりに2軸に分類**してみました。

<div align="center" style="padding: 16px 0;"><img src="../../data/input/katakana_classification_matrix.png" width="500"><br>カタカナ語の2軸分類</div>

軸は**「語義」（横軸）と「固有性」（縦軸）**の2つ。横軸の「語義」は**そのワードが何を指しているか**で、住居の型（種別）→ 場所・自然（地理特徴）→ 高級感・規模（抽象価値）→ 固有名詞（ブランド造語）と並びます。縦軸の「固有性」は**誰がそのワードを使えるか**で、誰でも自由に使える「完全一般化」→ 複数業者が使う「半一般化」→ 特定事業者しか使えない「ディベ固有」と上がっていきます。例えば**ハウス・ハイツ・コーポ**は完全な一般語で、誰でも自由に使えます。一方で**シャーメゾン（積水）・プラウド（野村）・ブリリア（東京建物）**などはディベブランドとして商標登録されており、特定の事業者しか使えません。

特に注目したいのはその中間、いわば「半一般化」の領域。**パーク・ガーデン・コート**あたりは元々「park = 公園」「garden = 庭」のような一般語なのに、何度も大手ディベのブランドに使われ続けた結果、「なんとなく高級そう」というイメージが染み付いています。本来は単なる一般語なのに、ブランド名でもないのに、なんとも微妙な立ち位置にあるワード群です。

私は今まで何度も山手の方に住んでいたのでヒルズは特に馴染みがあります。**"hill: 丘"という意味**と、**森ビルのブランド的側面**（六本木ヒルズ・表参道ヒルズ、他に住友不動産のグランドヒルズなど）もあるので、半一般化の代表として挙げました。ディベブランドは時代によって変遷しているのも面白いところです。ブランド名をまとめているサイトもあるので興味ある方はご参考に: https://www.all-mansion.com/brand/

ヒルズに限らず、こうした「ある時期に強いブランドに使われ → 徐々に一般語化していく」という変遷は、不動産命名の歴史をたどると結構頻繁に見かけます。一旦ブランドとして認知されたワードは"高級そう"なイメージが定着し、それを真似する形で他社も使うようになり、結果としてブランドとしての特別感は薄まっていく。ハイツがほぼ完全に一般語化したのも、おそらくこの経路を辿った結果なんでしょう。命名の世界はマーケティングと言語の進化が混ざり合っていて、データを並べて眺めるとその過渡期の様子が見えてきます。

### 純和風な「○○荘」は今でも生き残っているのか？

**544件**でした。top10最下位のパレス(845件)には届かないものの、**意外と多い**と感じた人も多いのではないでしょうか。この辺りは古い建物が多いエリアなど場所による偏りが出るかもしれません。前述の意味軸とも密接に関わるので詳しくみてみます。

「○○荘」は昭和期、特に戦後から高度成長期にかけて、木造アパート命名の代表格でした。学生向けの下宿や小規模な2階建てに「○○荘」と名付けるのが一般的で、今でも「荘」と聞くと下宿を思い浮かべる人は多いのではないでしょうか。今となっては築古・低家賃帯の物件に偏っているのでは、と推測できますが、それでも500件以上残っているのは、昭和に建てられた建物がまだ現役で使われている可能性が高そうです。

カタカナ命名が「新しさ・オシャレさ」を売る方向に振っているのに対して、漢字一文字の「荘」は「素朴さ・親しみ」を担っている。両者が併存しているところに、日本の賃貸物件の名付けのバリエーションを感じます。ちなみに「荘」と並ぶ昭和系の語尾には「館」「邸」「ハイム」（独: Heim = 家）なんかもありますが、それぞれ多少響きの違いを感じます。「ハイム」は和洋折衷感、「館」は格式、「邸」は重厚感、と微妙に役割分担している印象です。なお「館」については、ちょっと毛色が違いますが、「○号館」のように、大規模な団地や複数棟の物件で棟を区別する目的で使われることもありますね。

ランキングからは、ハイツ・メゾンを筆頭に馴染み深いワードが上位を占める一方、その背景には**地理・ブランド・建物特徴など複数の意味軸が絡み合っている**ことも見えてきました。

ここで気になるのは、複数の意味軸の中でも特に**「地形」を表すワード**たち。ヒルズやベイは語義通りの場所に分布しているのか？次章では**標高データから検証**してみます。

## 2. ヒルズは本当に丘にあるのか？

カタカナ語の意味をいくつかにタイプ分けして考えると、**地形を表すものが複数存在**していることがわかります。ここに注目して標高との関係を調べてみます。緯度経度に対する標高データは**国土地理院が公開**しているので、23区内の各地域の代表地点の緯度経度から標高を割り出して集計してみましょう。

今回フォーカスするのは、**ヒルズ・スカイ・ベイ・リバー・ポート・フォレスト**といった、いかにも自然や地形を連想させるワード6つ。これらは命名段階で「土地の特徴を売りにしている」可能性が高いので、本当にその通りの場所にあるのかを確かめるには最適です。「ヒルズなんだから丘の上にあるだろう」みたいな素朴な予想が当たっているのか、データで確かめてみます。

<div align="center" style="padding: 16px 0;"><img src="../../data/010_visualize_name_elevation/index.png" width="500"><br>カタカナ語 x 標高</div>

**ヒルズの平均標高は23.0m（全体平均+3.2m）**と、文字通り高い位置に分布する結果になりました！その他にも**ベイ(平均10.3m、−9.5m)、リバー(平均8.9m、−10.9m)など水辺を連想させるワードは標高が顕著に低い**ことも判明し、地形系ワードはイメージと一致する分布を示すようです。

23区の地形をざっくり知っておくと、この結果はかなり納得感があります。23区西側（世田谷・目黒・文京・新宿など）は**武蔵野台地という標高15〜30m級の高台**で、東側（江東・葛飾・足立・墨田）は隅田川・荒川が作った**沖積平野でほぼ標高0〜5mの低地**。「ヒルズ」が分布するのは前者、「ベイ」「リバー」が分布するのは後者、という関係性がそのまま標高にも出ています。

一方で**スカイ(平均16.7m、全体平均−3.0m)が低いのは意外**でした。高台を想起させるワードですが、低地に多いようです。高台という意味ではなく、**建物自体が高いタワマン**ということかもしれません。実際、港区の港南・芝浦エリアや江東区の豊洲・有明など、タワマンが集中する場所は低地なので、「空に近い」のは標高ではなく階数の話、ということなのかもしれません。

もっとも、これはあくまで「平均」の話で、個別の物件で見れば例外はいくらでもあるはず。同じ「スカイ」でも、目黒区や品川区の高台にある低層物件もあれば、ベイサイドの低地に建つ大規模タワマンもあると思います。今回見えているのは、あくまで全体をならしたときの傾向にすぎません。一件一件の名付けの理由はもっとバラバラなはずで、その前提で眺めておくのがよさそうです。

地形系ワードは概ね言葉通りの場所に分布する一方、**スカイのような例外**もあり、**ワードの背後に地域固有の文脈が潜んでいる**ことが示唆されました。

つまり単純な標高だけではなく、**地域的な特徴と関係が深い**ということ。次章では**23区別の分布**から、地域とカタカナ語の関係性をさらに掘り下げてみます。

## 3. 港区にはタワーが本当に多いのか？

先ほどのカタカナ語の**23区ごとの分布**をいくつか見てみましょう。標高と区はある程度相関があるはずなのと、**エリア特性も相まって面白い分布**が期待できます。

<div align="center" style="padding: 16px 0;"><img src="../../data/011_visualize_token_by_area/tower.png" width="500"><br>"タワー" x 23区の分布</div>

**タワーは本当に港区にありました**！港区だけで79件、出現率は**23区平均の7.16倍**とダントツ。ベイエリアにくっきり偏って分布しており、そのほか千代田区(16件、4.28倍)・中央区(23件、3.27倍)・品川区(28件、2.11倍)などベイ付近にも集中しています。**タワマンが多いエリア特性をもろに反映**した結果と言えそうです。

具体的なエリアとしては、港区なら港南・芝浦・白金高輪・虎ノ門あたり、中央区なら勝どき・晴海・月島、江東区なら豊洲・有明あたりが思い当たります。多くはここ20〜30年の湾岸再開発で生まれた高層タワマン街で（白金高輪・虎ノ門は湾岸ではなく内陸の再開発組ですが）、命名の段階で「タワー」を入れて立地特性を主張する戦略がすっかり定着している印象。千代田区の4.28倍も気になるところで、オフィス街のイメージが強い区ですが、番町・九段・富士見・神田あたりにタワマンが点在していて、それが数字を押し上げているようです。「タワー」というワード1つで、その区の不動産マーケットの輪郭が見えてくるのは、結構乙な発見でした。

では他の名前はどうでしょうか。

<div align="center" style="padding: 16px 0;"><img src="../../data/011_visualize_token_by_area/hills_sky_bay_river.png" width="500"><br>カタカナ語 x 23区の分布</div>

**ベイは港区・中央区・江東区の湾岸エリアに集中**（港区・江東区はいずれも出現率が平均の5〜7倍）。これは**豊洲・有明・お台場といった湾岸再開発のワード**であることを示しています。一方**リバーは隅田川・荒川沿いに広く分布**し、湾岸タワマンエリア（江東区・中央区）に加えて葛飾区・足立区など下町川沿い物件にも及んでいる。同じ「水辺」でも、**ベイは高級湾岸文化、リバーはより広い水辺文化**を反映している、と言えそうです。

今回のデータでベイを冠する物件を見てみると、東京ベイシティタワーやベイサイドタワー晴海のような、湾岸エリアの大規模物件が並びます。90年代以降の再開発と並行して「ベイ」というワードが「**未来感・グローバル感**」を売りにするワードとして使われてきた歴史がありそうです。

一方で「リバー」は、もっと身近で生活感のある使われ方をしている。隅田川や荒川、神田川沿いに小規模な物件が広く分布していて、対象は湾岸タワマン購入層というより、**川沿いの落ち着いた住環境を求める一般層**といったところでしょうか。同じ水辺でも、ベイは「港を見下ろす」、リバーは「川沿いを散歩する」、くらい違うイメージなんじゃないかと思います。物件名のワード1つでこれだけ違う物件像を想像できるのは楽しいですね。

### スカイはタワマンを意味していない？

**スカイの最大集中エリアは、港区でも江東区でもなく墨田区**でした（出現率は23区平均の約2.5倍）。隣接する台東区(約1.8倍)・中央区(約1.8倍)も高い。これは何を意味するのか?

ここで思い当たるのが**東京スカイツリー（墨田区押上）**です。湾岸タワマンの「空に近い」ではなく、**「スカイツリーが見える」という意味**で使われているのではないでしょうか。2012年の開業前後で墨田区・台東区の不動産マーケティングは大きく変わったと言われ、「スカイツリービュー」「徒歩○分」が広告の定番に。物件名に「スカイ」を入れるのも、その流れで立地をアピールしているのだと思います。似た例はほかにもあって、ヒルズが森ビルブランドと結びつくように、**近くのランドマークの名前を借りて「その土地らしさ」を物件名に纏わせる**手法は意外と一般的です。

もちろん、「スカイ」物件の多くが昭和〜平成初期のもので、開業とは無関係にただ「空」を意味する一般語だった、という可能性も残ります。ただ、墨田区の2.5倍（※1）という偏りには何かしらの説明が要るわけで、スカイツリー開業以降の命名トレンドがこれを生んだ、と考えるほうがやはり筋は通る気がします。裏づけるには**開業前後の墨田区周辺の物件名**を調べる必要がありますが、もし正しければ**一見地理的なワードが、実はランドマークを指していた**という面白い結果になります。

23区別に見ると、カタカナ語は**単なる地理的特徴のラベルではなく、地域ごとの都市文化をも反映するもの**として機能していました。タワーは港区のタワマン文化を、ベイは湾岸再開発を、リバーは下町の水辺暮らしを、スカイはスカイツリーを参照している。賃貸物件名だけでこれだけ多様な文化的背景が見えてくるのは、横断的に集計するからこそ見える発見です。

## おわりに

賃貸マンション名のカタカナ語を縦にも横にも見てみると、思っていたよりずっと多くの情報が物件名には詰まっていました。ハイツ・メゾンの圧倒的なシェア、ちゃんと高台にあったヒルズ、そしてスカイツリーを指していた「スカイ」。それぞれの裏に、命名のトレンドや地形、ランドマークの開業といった出来事が見え隠れしています。

物件名は普段ただの記号として読み流してしまいますが、集めて並べてみると、開発の時期や地形、マーケティングの狙いまで透けて見える、意外と情報量の多い手がかりでした。

ヒートマップにした途端、集計前には見えなかった構造がぽろっと出てくる瞬間があって、個人的にはここが結構好きです。今回もスカイの墨田区集中を見たときは、スカイツリー説に辿り着くまで少し時間がかかりましたが、わかってしまえば「なんで気付かなかったんだろう」という感じでした。街を歩いているだけではこういう構造はなかなか見えてこないので、データを通す意味はこういうところにあるんだと思います。

似た切り口で他にも気になる問いがあれば、コメントなどで教えていただけると嬉しいです。

**※ lift（リフト）**: 出現割合が全体平均の何倍かを表す指標。2.5倍なら平均の2.5倍含まれやすい、ということ。件数の大小に左右されず偏りを比較可能。
