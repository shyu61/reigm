# 東京23区賃貸マンション名に使われるカタカナ語ランキング

東京23区内には数万~数十万件規模で賃貸マンションが存在します。今回はSUUMOを使って賃貸マンションに使われるカタカナ語を調査してみました。

## 1. カタカナ語ランキング

今回はマンション名から形態素ごとにカタカナ語を抽出してランキング化しました。形態素で分割するとブランド名をバラバラにしちゃったりするので正確ではないと言えばそうなんですが、その点は後で補足するとして純粋に「ワードとして何が使われているか？」を調査しています。

<div align="center" style="padding: 16px 0;"><img src="../../data/005_visualize_token_counts/index.png" width="500"><br>賃貸物件カタカナ語ランキングtop10</div>

### ハイツ/メゾンが最も使われている！

メゾンに競り勝ちハイツが最も使われているという結果になりました。上位のものは特に皆さんにも馴染み深いのではないでしょうか。純粋にいろんな業者がハイツやメゾンを名前に使っているというのもありますし、積水ハウスの「シャーメゾン」のようなブランド名として多くのマンションが存在しているというのもありそうですね。

ハイツとヒルズは全然分類として意味が違う

カタカナ語を扱いで難しのは、背景にある意味がいくつかの軸で構成され一概に分類できない点です。ディベブランドとして商標登録されているものもあれば、商標登録はされてないが半固有化されているものなど。また地理的な意味を持つものもあれば、建物自体に意味を付加するようなものもあります。私なりに2軸に分類してみました。

<div align="center" style="padding: 16px 0;"><img src="../../data/input/katakana_classification_matrix.png" width="500"><br>カタカナ語の2軸分類</div>

私は今まで何度も山手の方に住んでいたのでヒルズは特に馴染みがあります。"hill: 丘"という語義と、六本木ヒルズ・表参道ヒルズなど森ビルのブランド的側面（他に住友不動産のグランドヒルズなど）もあるので半一般化の代表として挙げました。 ディベブランドは時代によって変遷しているのも面白いところです。 ブランド名をまとめているサイトもあるので興味ある方はご参考に: https://www.all-mansion.com/brand/

### 純和風な名前は？「○○荘」は人気なのか

544件でした。top10入りとはなりませんでしたが意外と多いと感じた人も多いのではないでしょうか。この辺りは古い建物が多いエリアなど場所による偏りが出るかもしれません。前述の語義とも密接に関わるので詳しくみてみます。

## 2. ヒルズは本当に丘にあるのか？

カタカナ語の意味はいくつかにタイプ分けして考えると、地形を表すものが複数存在していることがわかります。ここに注目して標高との関係を調べてみます。緯度経度に対する標高データは国土地理院が公開しているので23区内の各地域の代表地点の緯度経度から標高を割り出して集計してみましょう。

<div align="center" style="padding: 16px 0;"><img src="../../data/010_visualize_name_elevation/index.png" width="500"><br>物件トークン名 x 標高</div>

ヒルズは予想通り高い位置にあるという結果になりました！その他にもポートやベイなど東京湾を連想させるワードだと標高が低いという結果になったのも予想を裏付ける結果でした。

一方でスカイが低いのは意外でした。高台を想起させるワードですが低地に多いようです。高台という意味ではなく、建物自体が高いタワマンということかもしれません。港区などのタワマンエリアの多くは低地に位置しています。

この予想からも単純な標高だけではなく、むしろ地域的な特徴と関係が深いことがわかります。最後に地域的な特徴とカタカナ語の関係性を見てみます。

## 3. 港区にはタワーが本当に多いのか？

先ほどの物件トークン名の23区ごとの分布をいくつか見てみましょう。標高と区はある程度は相関があるはずなのと、エリア特性も相まって面白い分布が期待できます。

<div align="center" style="padding: 16px 0;"><img src="../../data/011_visualize_token_by_area/tower.png" width="500"><br>"タワー" x 23区の分布</div>


タワーは本当に港区にありました！明らかにベイエリアに集中しています。そのほか千代田区・中央区・品川区などベイ付近に集中しています。タワマンが多いエリア特性をもろに反映していますね。

では他の名前はどうでしょうか。

<div align="center" style="padding: 16px 0;"><img src="../../data/011_visualize_token_by_area/hills_sky_bay_river.png" width="500"><br>物件トークン x 23区の分布</div>

ベイは港区・中央区・江東区の湾岸エリアに集中。これは豊洲・有明・お台場といった湾岸再開発のワードであることを示しています。一方リバーは隅田川・荒川沿いに広く分布し、湾岸タワマンエリアに加えて墨田区・葛飾区・足立区の下町川沿い物件にも及んでいる。同じ「水辺」でも、ベイは高級湾岸文化、リバーはより広い水辺文化を映している、と言えそうです。

### スカイはタワマン参照ではない？

スカイの最大集中エリアは港区でも江東区でもなく、墨田区でした。隣接する台東区・中央区も高い。これは何を意味するのか?

ここで思い当たるのが東京スカイツリー(墨田区押上)です。スカイツリー周辺の再開発、あるいはスカイツリーが見える物件が「スカイ」というワードを使っている可能性が高い。湾岸タワマンの「空に近い」という意味ではなく、「東京スカイツリーが見える」という意味として機能しているということが見えてきます。

この仮説を裏付けるにはスカイツリー開業後前後での墨田区近辺の物件名を調査する必要がありそうです。もしこの仮説が正しいなら、一見地理的特徴を表していそうなワードが、実はランドマークを表すワードだったという面白い結果になります。一筋縄で行かないところが面白いところです。
