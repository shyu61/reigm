# 東京23区賃貸マンション名に使われるカタカナ語ランキング

東京23区内には**数万~数十万件規模**で賃貸マンションが存在します。今回はSUUMOから物件名を取得し、**マンション名に使われるカタカナ語**を調査してみました。

## TL;DR

1. カタカナ語ランキングでは、メゾンを僅差で抑えて**「ハイツ」が1位**。上位は馴染み深いワードが並ぶ
2. **「ヒルズ」は実際に標高の高い場所に多く**、「ベイ」「ポート」は低地に多いなど、地形系ワードは概ね地理的特徴と一致する
3. 一方で「スカイ」は意外にも低地に多く、**最大集中エリアは墨田区**。湾岸タワマンの「空」ではなく、**東京スカイツリーを参照している可能性**が浮上
4. 「タワー」は港区などベイエリアに集中、「リバー」は隅田川・荒川沿いに広く分布するなど、**ワードごとに異なる都市文化が映し出されている**

## 1. 賃貸マンション名で最も使われているカタカナ語は？

今回はマンション名から**形態素ごとにカタカナ語を抽出**してランキング化しました。形態素で分割するとブランド名をバラバラにしちゃったりするので正確ではないと言えばそうなんですが、その点は後で補足するとして、純粋に**「ワードとして何が使われているか？」**を調査しています。

<div align="center" style="padding: 16px 0;"><img src="../../data/005_visualize_token_counts/index.png" width="500"><br>賃貸物件カタカナ語ランキングtop10</div>

### ハイツ vs メゾン、勝つのはどっち？

メゾン（1459件）をわずか**15件差で抑えて、ハイツ（1474件）が堂々の1位**という結果になりました。上位10位までは800件以上が並ぶ激戦区で、皆さんにも馴染み深いワードが揃っています。純粋にいろんな業者がハイツやメゾンを名前に使っているというのもありますし、**積水ハウスの「シャーメゾン」のようなブランド名**として多くのマンションが存在しているというのも一因かもしれません。

**ハイツとヒルズは、実は全然違う分類**

カタカナ語を扱う上で難しいのは、**背景にある意味がいくつかの軸で構成され、一概に分類できない**点です。ディベブランドとして商標登録されているものもあれば、商標登録はされてないが半固有化されているものもあります。また地理的な意味を持つものもあれば、建物自体に意味を付加するようなものもあります。試しに**私なりに2軸に分類**してみました。

<div align="center" style="padding: 16px 0;"><img src="../../data/input/katakana_classification_matrix.png" width="500"><br>カタカナ語の2軸分類</div>

私は今まで何度も山手の方に住んでいたのでヒルズは特に馴染みがあります。**"hill: 丘"という語義**と、**森ビルのブランド的側面**（六本木ヒルズ・表参道ヒルズ、他に住友不動産のグランドヒルズなど）もあるので、半一般化の代表として挙げました。ディベブランドは時代によって変遷しているのも面白いところです。ブランド名をまとめているサイトもあるので興味ある方はご参考に: https://www.all-mansion.com/brand/

### 純和風な「○○荘」は今でも生き残っているのか？

**544件**でした。top10最下位のパレス(845件)には届かないものの、**意外と多い**と感じた人も多いのではないでしょうか。この辺りは古い建物が多いエリアなど場所による偏りが出るかもしれません。前述の語義とも密接に関わるので詳しくみてみます。

ランキングからは、ハイツ・メゾンを筆頭に馴染み深いワードが上位を占める一方、その背景には**地理・ブランド・建物特徴など複数の意味軸が絡み合っている**ことも見えてきました。

ここで気になるのは、複数の意味軸の中でも特に**「地形」を表すワード**たち。ヒルズやベイは語義通りの場所に分布しているのか？次章では**標高データから検証**してみます。

## 2. ヒルズは本当に丘にあるのか？

カタカナ語の意味をいくつかにタイプ分けして考えると、**地形を表すものが複数存在**していることがわかります。ここに注目して標高との関係を調べてみます。緯度経度に対する標高データは**国土地理院が公開**しているので、23区内の各地域の代表地点の緯度経度から標高を割り出して集計してみましょう。

<div align="center" style="padding: 16px 0;"><img src="../../data/010_visualize_name_elevation/index.png" width="500"><br>物件トークン名 x 標高</div>

**ヒルズの平均標高は約23m（全体平均+約3m）**と、語義通り高い位置に分布する結果になりました！その他にも**ベイ(平均約10m、-約10m)、リバー(平均約9m、-約11m)など水辺を連想させるワードは標高が顕著に低い**ことも判明し、地形系ワードはイメージと一致する分布を示すようです。

一方で**スカイ(平均約17m、全体平均-約3m)が低いのは意外**でした。高台を想起させるワードですが、低地に多いようです。高台という意味ではなく、**建物自体が高いタワマン**ということかもしれません。実際、港区などのタワマンエリアの多くは低地に位置しています。

地形系ワードは概ね語義通りの場所に分布する一方、**スカイのような例外**もあり、**ワードの背後に地域固有の文脈が潜んでいる**ことが示唆されました。

つまり単純な標高だけではなく、**地域的な特徴と関係が深い**ということ。次章では**23区別の分布**から、地域とカタカナ語の関係性をさらに掘り下げてみます。

## 3. 港区にはタワーが本当に多いのか？

先ほどの物件トークン名の**23区ごとの分布**をいくつか見てみましょう。標高と区はある程度相関があるはずなのと、**エリア特性も相まって面白い分布**が期待できます。

<div align="center" style="padding: 16px 0;"><img src="../../data/011_visualize_token_by_area/tower.png" width="500"><br>"タワー" x 23区の分布</div>

**タワーは本当に港区にありました**！港区だけで79件、出現率は**23区平均の約7倍**とダントツ。ベイエリアにくっきり偏って分布しており、そのほか千代田区(16件・約4倍)・中央区(23件・約3倍)・品川区(28件・約2倍)などベイ付近にも集中しています。**タワマンが多いエリア特性をもろに反映**した結果と言えそうです。

では他の名前はどうでしょうか。

<div align="center" style="padding: 16px 0;"><img src="../../data/011_visualize_token_by_area/hills_sky_bay_river.png" width="500"><br>物件トークン x 23区の分布</div>

**ベイは港区・中央区・江東区の湾岸エリアに集中**（港区・江東区がいずれも13件、出現率は平均の5〜7倍）。これは**豊洲・有明・お台場といった湾岸再開発のワード**であることを示しています。一方**リバーは隅田川・荒川沿いに広く分布**し、湾岸タワマンエリア（江東区16件・中央区15件）に加えて葛飾区(13件)・足立区(13件)など下町川沿い物件にも及んでいる。同じ「水辺」でも、**ベイは高級湾岸文化、リバーはより広い水辺文化**を映している、と言えそうです。

### スカイはタワマン参照ではない？

**スカイの最大集中エリアは、港区でも江東区でもなく墨田区**でした（37件、出現率は23区平均の約2.5倍）。隣接する台東区(約1.8倍)・中央区(約1.8倍)も高い。これは何を意味するのか?

ここで思い当たるのが**東京スカイツリー（墨田区押上）**です。スカイツリー周辺の再開発、あるいは**スカイツリーが見える物件が「スカイ」というワードを使っている**可能性が高い。湾岸タワマンの「空に近い」という意味ではなく、**「東京スカイツリーが見える」という意味として機能している**ということが見えてきます。

この仮説を裏付けるには**スカイツリー開業前後での墨田区近辺の物件名**を調査する必要がありそうです。もしこの仮説が正しいなら、**一見地理的特徴を表していそうなワードが、実はランドマークを表すワードだった**という面白い結果になります。一筋縄で行かないところが面白いところです。

23区別の分布からは、カタカナ語が**単なる地理的特徴のラベルではなく、湾岸再開発・下町文化・ランドマークといった地域ごとの都市文化を映し出すレンズ**として機能していることが見えてきました。
